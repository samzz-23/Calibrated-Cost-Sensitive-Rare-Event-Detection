# Project Context

## Project title

Calibrated Cost-Sensitive Learning for Rare-Event Detection

## Project objective

Investigate calibrated probability estimation and cost-sensitive decision thresholds for detecting rare undesirable events in industrial sensor data using the official Petrobras 3W Dataset.

## Current research/problem question

How can calibrated probabilities and cost-sensitive decision thresholds improve rare-event detection when false alarms and missed events have asymmetric costs?

## Dataset

Petrobras 3W Dataset

## Current status

Project initialization

## Decisions made so far

- Use the official Petrobras 3W Dataset
- Focus on rare-event detection
- Investigate probability calibration
- Investigate cost-sensitive decision thresholds
